# Bettdow Smartwatch — arquivos de imagem

Envie os 9 arquivos PNG originais nesta pasta:

- `relogio-1.png` até `relogio-9.png`

Esses nomes são usados pela galeria e pela descrição da rota `/relogio`.
Use os arquivos originais 800 px do pacote de imagens HD para preservar a qualidade.

Não é necessário converter, comprimir ou redimensionar as imagens.

## Seletor de cores

Envie também os 2 PNGs originais para esta pasta, sem alterar seus nomes ou compactar as imagens:

- `preto.png` — relógio preto
- `branco.png` — relógio branco

A rota `/relogio` usa os arquivos acima nas duas opções de cor, na foto selecionada e no checkout. Os arquivos devem ser enviados antes de publicar o novo layout.
