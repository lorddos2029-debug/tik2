# Imagens originais do Basic Whey Protein 1Kg

Para mostrar as imagens de alta qualidade na Vercel, coloque aqui os quatro arquivos originais, sem reduzir a resolução:

- `natural.png`
- `chocolate.png`
- `morango.png`
- `baunilha.png`

A página `/whey` utiliza esses arquivos na galeria, na descrição, no seletor de sabores e no checkout. O projeto serve os arquivos em `/products/whey/` na raiz do domínio.

Não use miniaturas nem capturas de tela recomprimidas. Se os arquivos originais forem JPEG/WebP, atualize também as extensões em `src/lib/whey-catalog.ts`.
